# Cours et TP Virtualisation

![LaMeDuSe_LOGO](/img/LaMeDuSe_logo.webp)

Ce dossier contient les travaux pratiques liés à la **virtualisation** : création de machines virtuelles, installation de systèmes from scratch et préparation de modèles (*golden images*) réutilisables.

## Structure
- `tp/` : Travaux pratiques, chacun avec son README détaillant les objectifs et étapes.

Chaque TP possède son propre README qui explique les objectifs et les exercices à réaliser.
